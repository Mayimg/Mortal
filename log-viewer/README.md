# Log Viewer for mjai

This component is copied and modified from the artifacts generated by [gimite/mjai](https://github.com/gimite/mjai).

## 使い方 / Usage

### 外部ファイル読み込み版 (External file loading version)

`index.html`を使用すると、MJAI形式の牌譜ファイルを外部から読み込んで再生できます。

1. `index.html`をWebブラウザで開きます
2. 「Choose File」ボタンをクリックしてMJAI形式の牌譜ファイルを選択します
   - 対応形式：`.json`, `.jsonl`, `.txt`, `.gz`（gzip圧縮されたJSONファイル）
3. ファイルが正常に読み込まれると、牌譜再生画面が表示されます
4. 別の牌譜を見たい場合は、再度ファイルを選択できます（ファイル選択ボタンは常に表示）

### 埋め込み版 (Embedded version)

`index.example.html`は牌譜データが直接埋め込まれたサンプルです。

## 操作方法 / Controls

- **Prev/Next**: アクションを前後に移動
- **Go**: 指定したアクション番号に移動
- **Last**: 現在の局の最後のアクションに移動
- **局選択**: ドロップダウンから局を選択
- **Viewpoint**: プレイヤー視点を切り替え（+マークが現在の視点）
- **マウスホイール**: アクションを前後に移動

## ファイル形式 / File Format

MJAI形式（改行区切りJSON）に対応しています。各行が1つのアクション（JSON）を表します。

例：
```
{"type":"start_game","names":["player1","player2","player3","player4"]}
{"type":"start_kyoku","bakaze":"E","kyoku":1,"honba":0,...}
{"type":"tsumo","actor":0,"pai":"1s"}
...
```

## サンプルファイル / Sample Files

- `sample.jsonl` - 通常のMJAI形式牌譜データ
- `sample.jsonl.gz` - gzip圧縮されたMJAI形式牌譜データ

## ブラウザサポート / Browser Support

gzip圧縮ファイル（.gz）の読み込みには、DecompressionStream APIをサポートする最新のブラウザが必要です：
- Chrome/Edge 80+
- Firefox 113+
- Safari 16.4+

古いブラウザを使用している場合は、圧縮されていないファイル（.jsonl）を使用してください。
